# Resposive Signup Form
A modern signup responsive form built with HTML, Tailwind CSS, and JavaScript.

## 🚀 Features
- Responsive Design
- Form Validation
- Password Strength Meter
- Show/Hide Password Toggle
- Character Counter
- Age Validation
- Success Modal
- Mobile Friendly UI

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
